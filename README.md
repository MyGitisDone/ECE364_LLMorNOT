# Transformer-Based LLM Essay Detection

A lightweight Transformer encoder for detecting whether an essay was written by a human student or generated by a Large Language Model (LLM).

Built as a course project for ECE 364 — Programming Methods for Machine Learning.

## Overview

This project implements a custom Tiny-BERT style encoder architecture for binary text classification under a strict 15M parameter constraint.

The model analyzes essays and predicts the probability that the text was generated by an LLM rather than written by a student.

Despite using only **12.2M parameters**, the model achieved:

* **0.9992 ROC-AUC** on the Kaggle public leaderboard
* **0.9977 ROC-AUC** on local validation

The project focuses on:

* Transformer encoder architectures
* Efficient parameter scaling
* NLP classification pipelines
* Training optimization on Apple Silicon (MPS)

---

# Architecture

The model is based on a lightweight BERT-style encoder architecture optimized for classification tasks.

## Tiny-BERT Configuration

| Component         | Value      |
| ----------------- | ---------- |
| Hidden Layers     | 4          |
| Hidden Dimension  | 256        |
| Attention Heads   | 8          |
| Intermediate Size | 1024       |
| Vocabulary Size   | 30522      |
| Total Parameters  | 12,221,441 |

A `[CLS]` token is prepended to every sequence, and its final hidden representation is used for binary classification through a linear classification head.

## Why Encoder-Only?

Because the task is classification rather than text generation, a bidirectional encoder architecture is more suitable than an autoregressive decoder. The encoder allows every token to attend to the entire essay context simultaneously.

# Training Pipeline

## Tokenization

* WordPiece tokenizer
* Maximum sequence length: 256
* Padding and truncation applied uniformly

## Dataset Split

* 90/10 stratified train-validation split

## Training Hyperparameters

| Hyperparameter | Value    |
| -------------- | -------- |
| Optimizer      | AdamW    |
| Learning Rate  | 3e-5     |
| Batch Size     | 16       |
| Loss Function  | BCE Loss |
| Epochs         | 3        |
| Random Seed    | 42       |

## Regularization

To reduce overfitting:

* Dropout applied to attention layers and classification head
* Weight decay via AdamW
* Training limited to 3 epochs
